# Solver oracle

Generated by `cargo xtask solver-oracle`. Each case is a sketch with named dimensions and a run of dimension edits (`plan/fusion/solver-oracle/<case>/case.json`, local, not committed). Fusion built each case and recorded, after every edit, where each point landed and whether the values took (`measure.json`, local, never committed). SolveCraft builds the same sketch with its sketch commands, applies the same edits in the same order (all values of an edit in one recompute with `parameters.import`, or one `parameters.change` after another where Fusion applied them one by one) and compares:

- **same**: every point within 1e-3 mm of Fusion's;
- **mirrored**: both solved, and three mutually related points (dimensioned, joined by a line or arc, or both fixed) turn the other way, or a horizontal/vertical offset or line points the other way;
- **different**: both solved, another placement with the same orientations;
- **we refused** / **Fusion refused**: only one of them took the values (SolveCraft: once all of an edit's values are applied, the sketch does not solve or does not measure them; the edit is then undone before the next one, as Fusion keeps the values it held. Fusion: the parameters do not hold the requested values, whatever the sketch's health); **both refused**.

Mirrored, different and we-refused edits need a reason in `xtask/data/solver-oracle-known.tsv` (case, edit, reason), or the task fails.
